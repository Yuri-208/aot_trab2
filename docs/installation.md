# Installation

## Instalação e Configuração

Para simular o projeto corretamente, siga os passos abaixo:

1. Baixe o simulador UnoArduSim:
   - [Site oficial](https://sites.google.com/site/unoardusim/home?authuser=0)

2. Descompacte o arquivo `UnoArduSimV2.9.2.zip` em uma pasta.

3. Baixe os arquivos do projeto e salve na mesma pasta:
   - `base_trab_2.ino`
   - `ino_config.txt`
   - `myArduPrefs.txt`

4. Abra o UnoArduSim e carregue o arquivo `base_trab_2.ino`.

5. Execute a simulação e observe o comportamento dos LEDs conforme os interruptores são ativados.

> Todos os arquivos estão disponíveis no repositório GitHub.
