# aot_trab2

## Descrição do Projeto

Este projeto simula um sistema digital embarcado utilizando o microcontrolador Arduino, com foco na lógica de somador completo. O sistema recebe entradas binárias através de interruptores e exibe os resultados em LEDs coloridos. O objetivo principal é aplicar conceitos de programação embarcada, lógica digital e boas práticas de desenvolvimento de software, como documentação, controle de versão e licenciamento.

## Funcionalidades

- Leitura de entradas digitais (pinos 0 a 7)
- Controle por botão (pino 13)
- Exibição de resultados em LEDs (pinos 8 a 12)
- Implementação da lógica de somador completo
- Comentários explicativos em inglês no código
- Documentação bilíngue (PT/EN)
- Licença MIT aplicada

## Componentes Simulados

| Componente           | Pino | Função                     |
|----------------------|------|----------------------------|
| Botão de pressão     | 13   | Aciona a lógica principal  |
| Interruptores        | 0–7  | Representam bits de entrada |
| LEDs coloridos       | 8–12 | Exibem o resultado lógico  |
