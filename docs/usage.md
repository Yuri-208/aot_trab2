# Usage

## Como Utilizar o Sistema

Este sistema simula a soma binária de dois bits com carry-in. Veja como interagir com ele:

### Entradas

- Ative os interruptores conectados aos pinos 0 a 7 para definir os bits de entrada.
- Pressione o botão no pino 13 para acionar a lógica.

### Saídas

- Os LEDs nos pinos 8 a 12 acenderão conforme o resultado da operação lógica.
- O LED correspondente à soma acenderá se o resultado for 1.
- O LED de carry acenderá se houver transporte.

### Testes

- Teste diferentes combinações de bits.
- Observe como a lógica do somador completo responde às variações.

> Use o simulador UnoArduSim para visualizar os resultados em tempo real.
